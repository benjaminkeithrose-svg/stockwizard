# stockwizard

Technical trading workspace: charts, scanner, backtester and, later, a paper-trading bot.

- `SPEC.md`: the build brief for Claude Code
- `PROPOSAL.md`: the reasoning behind it
- `CLAUDE.md`: how Claude Code works in this repository
- `backend/`: Python indicators, candle loader
- `web/`: the chart workspace web app
- `supabase/`: database migrations and their security checks
